1. SOCKET.IO — Complete Implementation
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Namespace: /customer
- authenticate middleware (verify JWT on connect)
- join room: order:{orderId}
Events received from customer:
  'send_message' → save to OrderMessage, emit to store
  'substitution_response' → update DB, notify store
  'im_here_curbside' → notify store, update order
Events emitted to customer:
  'order_status' → any status change
  'new_message' → from store
  'substitution_request' → approval needed
  'order_ready' → with QR code data

Namespace: /store
- authenticate + verify store ownership
- join rooms: store:{storeId}, order:{orderId}
Events received from store:
  'order_status_update' → update DB + notify customer
  'item_status_update' → update OrderItem
  'meat_weight_update' → recalculate, update PaymentIntent
  'substitution_request' → notify customer
  'send_message' → save, emit to customer
  'mark_ready' → update status, send notifications
  'curbside_delivered' → complete order
Events emitted to store:
  'new_order' → with full order data + sound trigger
  'order_cancelled' → customer cancelled
  'substitution_approved/rejected' → customer response
  'customer_arrived' → curbside I'm Here pressed
  'new_message' → from customer

Namespace: /admin
- Admin only
- join room: 'admin_global'
Events emitted to admin:
  'new_order' → platform-wide new order
  'store_online/offline' → store status change
  'refund_requested' → needs attention

2. STRIPE — Complete Integration
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Order Payment Flow:
1. Customer places order → create PaymentIntent
   - amount = estimated total (includes meat estimate)
   - capture_method = 'manual' (pre-authorization)
   - metadata = { orderId, customerId, storeId }
2. Frontend confirms payment with Stripe.js
3. Payment authorized (not yet captured)
4. If no fresh meat → auto-capture immediately
5. If fresh meat → capture after store enters final weight
   - PATCH /api/payments/capture → Stripe capture API
   - Amount updated to final weight calculation

Webhook: /api/payments/webhook
Handle events:
- payment_intent.succeeded → confirm order, notify store
- payment_intent.payment_failed → notify customer
- payment_intent.canceled → cancel order
- charge.refunded → update DB, notify customer

Stripe Connect (store payouts):
- /api/store/connect/onboard → create Connect account link
- /api/admin/finance/trigger-payout:
  Calculate: gross - commission = net
  Create Stripe Transfer to store's Connect account
  Record in StorePayout table

Subscriptions:
- Create Stripe Customer on signup
- /api/subscriptions/subscribe → create Stripe Subscription
- Webhooks: customer.subscription.updated/deleted

4. CRON JOBS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Use node-cron:

recurringOrders.cron.js (every 15 min):
- Find RecurringOrders where nextOrderDate <= now + 30min
- Auto-create orders
- Charge saved payment method
- Update nextOrderDate
- Send confirmation to customer + notification to store

weeklyPayouts.cron.js (Monday 9 AM):
- Find all stores on weekly payout
- Calculate period gross revenue - commission
- Create Stripe Transfers
- Record in StorePayout
- Send earnings summary email to each store

loyaltyExpiry.cron.js (daily midnight):
- Find loyalty points expiring in 7 days → notify
- Expire points older than 12 months → mark expired

pickupSlots.cron.js (daily 1 AM):
- Generate pickup slots for next 7 days
- For each store × each operating day
- Create PickupSlot records based on store settings

analyticsRollup.cron.js (daily 2 AM):
- Aggregate yesterday's orders per store
- Save to StoreAnalytic table
- Update store rating averages

6. SECURITY HARDENING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
- helmet.js: full security headers
- CORS: whitelist frontend domain only
- Rate limiting: 
  Global: 200/min
  Auth endpoints: 10/min  
  Order creation: 5/min
- Input sanitization: DOMPurify + Zod on all inputs
- SQL injection: Prisma handles this (parameterized queries)
- XSS: Content Security Policy headers
- CSRF: double-submit cookie pattern for state-changing ops
- File upload: validate MIME type + max 5MB + scan
- Secrets: never in code, only env vars
- PIPEDA compliance (Canada): 
  Privacy policy page
  Cookie consent banner
  Data deletion endpoint: DELETE /api/profile (full account)
  Data export endpoint: GET /api/profile/export
