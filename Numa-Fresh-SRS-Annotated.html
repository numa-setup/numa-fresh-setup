1. PRODUCT OVERVIEW

Numa Fresh Marketplace is a multi-portal, production-grade halal grocery marketplace. It connects customers with local halal stores for online ordering and express pickup. The platform operates on a store-fulfilled model — stores handle all picking, packing, and fulfillment. Fresh halal meat cut on demand is the platform's primary differentiator.

1.1 What Makes Numa Fresh Different

  • Store-Fulfilled: No platform shoppers or drivers — stores own the full fulfillment process
  • Pickup-First: Express pickup (under 60 seconds) and curbside are the primary order types
  • Custom Halal Meat: Cut on demand, weight-adjusted, charged by final actual weight
  • Halal Certified Only: Every store must hold a valid halal certificate, verified by admin
  • Muslim Community Focus: Eid/Qurbani system, Masjid partnerships, Urdu + Arabic language support
  • Full Transparency: Every fee shown explicitly at checkout — no hidden charges

2.1 Store Approval Flow

  1. Owner registers, navigates to /store-portal/onboarding (apply) and submits store application
  2. Store created with status: Pending — not visible to customers yet
  3. Admin reviews: business info, halal certificate document, operating hours — document viewer and full approval workflow not yet fully wired; admin can view stores in /admin/stores
  4. Admin APPROVES → store goes live on marketplace, owner receives email confirmation — email confirmation on approval not yet triggered automatically
  5. Admin REJECTS → reason stored, rejection email with reason sent to owner — rejection email flow not yet implemented
  6. Admin can add a store directly from /admin/stores, bypassing the application queue

3.4 Fresh Meat Product — Custom Order Modal

When a customer taps a Fresh Meat product, a 3-step customization modal opens before adding to cart:

  • Step 1 — Cut Type: Visual selection cards — Whole / Half / Quarter / Boneless / Bone-In / Cubed / Ground / Custom
  • Step 2 — Quantity: Weight selector (0.5 kg, 1 kg, 1.5 kg, 2 kg, or custom), estimated price auto-calculated
  • Step 3 — Instructions: Marination preference, packaging preference, free-text special instructions
Important: Fresh meat is priced by final actual weight. The amount shown is an estimate. The card is pre-authorized — final charge applied after cutting and weighing.

9. PAYMENT SYSTEM & SUBSCRIPTIONS

9.1 Customer Payments

  • All payments processed via Stripe — card details never touch platform servers

14. SECURITY & COMPLIANCE

14.1 Authentication & Authorization

  • All user sessions managed with JSON Web Tokens — access tokens expire in 15 minutes, refresh tokens in 7 days
  • Passwords stored using bcrypt hashing — raw passwords never stored
  • Google OAuth supported as an alternative login method — not yet implemented
  • Every API endpoint enforces role check — unauthorized access returns 403
  • All admin actions permanently recorded in the audit log

14.2 Data & API Security

  • Security headers applied to all responses via Helmet.js (prevents clickjacking, XSS, MIME sniffing)
  • Rate limiting on all endpoints — auth endpoints especially restricted (express-rate-limit)
  • All user inputs validated and sanitized before processing (Zod validation + express-mongo-sanitize)
  • File uploads restricted: type validation, maximum 5 MB per file — file upload validation not yet explicitly enforced
  • Payment card data never stored on platform — entirely handled by Stripe (PCI compliant)
  • Stripe webhook signatures verified on every incoming webhook event
